# 🚑 EMS Dispatch Simulation & Resource Optimization  
**Capstone Client Project – Simcoe County**

This repository contains a **capstone client project** focused on improving **Emergency Medical Services (EMS) dispatch efficiency** using data analytics and machine learning.  
The project simulates EMS call handling and predicts **resource requirements** to reduce response time and optimize operational planning.

---

## 🎯 Project Objective
The primary goal of this project was to:
- Analyze historical EMS call data
- Predict ambulance/resource demand
- Simulate dispatch decisions
- Support **faster response times** and **better resource allocation**

This project was designed and delivered as a **real-world client-style engagement**, including documentation, notebooks, and a final presentation.

---

## 🏥 Business Problem
Emergency response systems face challenges such as:
- Uneven demand across time and locations
- Limited ambulance availability
- Delays caused by inefficient allocation

Without predictive insights, dispatch decisions are often reactive rather than proactive.

---

## 🧠 Solution Overview
The project implements a **data-driven EMS dispatch simulator** that:
- Cleans and prepares historical EMS call data
- Engineers features related to time, location, and demand
- Uses machine learning to predict required resources
- Provides analytical outputs to guide dispatch planning
